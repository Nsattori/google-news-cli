# Caja Amazon Bolivia

App web para inventariar y vender los productos de una caja de devoluciones de Amazon en Bolivia.

- Foto del producto → la IA lo identifica y estima su precio (USD y Bs)
- Conversión con el tipo de cambio que elijas (oficial o paralelo)
- Enlaces para comparar: Amazon, eBay vendidos, Marketplace, Mercado Libre (Perú, Chile, Argentina), Google, TikTok
- Textos listos para Marketplace, WhatsApp y TikTok
- Resumen: cuánto llevas recuperado de lo que pagaste por la caja (1600 Bs)
